FAMILY WALL IMAGES

For public/non-sensitive images:
1. Put JPG/PNG/WebP files in this folder.
2. Edit data/family-wall.json.
3. Set the image field, for example:
   "image": "./assets/family-wall/weekend-01.webp"
4. Commit and push to GitHub. The updated picture will appear in the Family Wall.

PRIVACY WARNING
GitHub Pages sites are normally public. Do not place private family photos in this
folder unless you are comfortable with them being publicly reachable. For private
family content, enable the optional cloud backend and use private storage or signed
image URLs instead.
